## 2. Weibo

- **What a node is / label meaning.** BOND Appendix A.1.1: a user-posts-hashtag graph from Tencent-Weibo (a Twitter-like platform in China) covering 8,405 users and 61,964 hashtags. BOND uses the **user-user** graph provided by the original authors, which connects users who used the same hashtag. The graph is **directed** (the only directed dataset in BOND). Label rule: a user with at least five "suspicious events" (determined from temporal information) is suspicious; with none, benign. Suspicious users are the outliers. "Anomalous" therefore means a label derived from posting-time behaviour, not a structural or attribute pattern.
- **Features (400-d).** Concatenation of (1) post-location one-hot vectors summed per user and SVD-reduced to 100 dims and (2) bag-of-words of post text reduced to 300 dims. Timestamps were deliberately NOT put into the features because the labels were derived from them.
- **Provenance.** BOND cites [86] Zhao, Deng, Yu, Jiang, Wang, Jiang (2020), "Error-bounded graph anomaly loss for GNNs", CIKM 2020, pp. 1873-1882 (`zhao2020errorbounded`); data folder `weibo_s` in github.com/zhao-tong/Graph-Anomaly-Loss. That repository's README does not describe the data's origin (it only says where graph and label pickles live), so the Tencent-Weibo upstream source is only as described by BOND.
- **Caveats from BOND Sec. 4.1.** Weibo outliers show structural and contextual properties at once: average clustering coefficient 0.400 (outliers) vs 0.301 (inliers) and average neighbour-feature similarity 0.004 vs 0.993. Hence even non-neural detectors do very well (Table 4, ROC-AUC mean: Radar and ANOMALOUS 98.9, MLPAE 82.1, GCNAE 90.8, DOMINANT 85.0 +- 14.6 with max 92.5, AnomalyDAE 91.5). A near-ceiling score on Weibo does not show that a graph model learned anything graph-specific; compare to the feature-only MLPAE and to Radar. The large std for DOMINANT (14.6) is a reminder to report seeds and spread.
- **Licence / terms.** PyGOD data repository: MIT licence (repository level). Zhao et al. code repository: MIT licence. Terms of the underlying Tencent-Weibo data: **not stated** in any source opened. Redistribution rights of the raw data are therefore unconfirmed; the project uses the PyGOD copy only.

## 3. Reddit

- **What a node is / label meaning.** BOND Appendix A.1.1: a user-subreddit graph from one month of public Reddit posts. The 1,000 most active subreddits and the 10,000 most active users are extracted as subreddit nodes and user nodes; 168,016 interactions result. Each **user** has a binary label for "banned by the platform"; banned users are treated as outliers (366 of them). Subreddit nodes are therefore never anomalous. The 11,000 nominal nodes (1,000 + 10,000) differ from the 10,984 listed in Table 1; BOND does not explain the 16-node difference (not explained; do not invent a reason).
- **Features (64-d in BOND/PyGOD).** Text of each post converted to LIWC-category vectors; user and subreddit features are sums over their posts. The 64 dimension is as listed in BOND Table 1; the JODIE page opened does not describe the feature vector (UNVERIFIED how 64 relates to the original release).
- **Provenance.** BOND cites [44] Kumar, Zhang, Leskovec, "Predicting Dynamic Embedding Trajectory in Temporal Interaction Networks", KDD 2019 (`kumar2019jodie`; arXiv comment: accepted as an ACM SIGKDD 2019 research-track oral paper) and [73] Wang, Zhang, Guo, Yin, Li, Chen (SIGIR 2021) for the anomaly-detection use. Dataset download: `snap.stanford.edu/jodie/reddit.csv`.
- **Caveats.** BOND Sec. 4.1: Reddit outliers look like inliers in clustering coefficient and neighbour-feature similarity, so label meaning rests on domain annotation (bans). Unsupervised detectors are near chance (Table 4 ROC-AUC means: DOMINANT 56.0 +- 0.2, AnomalyDAE 55.7, GCNAE 50.6, MLPAE 50.6, Radar 54.9, LOF 57.2, IF 45.2, i.e. all between roughly 45 and 57; BOND's text quotes 0.604 as the best unsupervised value, which matches the max column of ANOMALOUS) against 0.746 for a supervised method from [73]. Expect weak anomaly-detection numbers; this is the dataset's nature, not necessarily a bug. Bans are an indirect, platform-policy label and may reflect behaviour unrelated to graph position or text.
- **Licence / terms.** SNAP JODIE page: no licence stated; it requests citation of the KDD paper if the datasets are used. PyGOD data repo: MIT (repository level). Reddit content terms: not stated in sources opened. Personal-data note: user-level post-derived data; the BOND text searched contains no licence or ethics statement for these datasets.

## 4. inj_cora (BOND/PyGOD injected Cora)

- **Official stats.** 2,708 nodes, 11,060 edges, 1,433 features, 70 contextual + 70 structural outliers, 138 total (5.1%); total is below 140 because some nodes carry both types (PyGOD data README, BOND Table 1).
- **Label encoding (data README).** 0 inlier, 1 contextual only, 2 structural only, 3 both; derive with `y.bool()`, `y >> 0 & 1` (contextual), `y >> 1 & 1` (structural). Local counts {1: 68, 2: 68, 3: 2} give contextual 68 + 2 = 70 and structural 68 + 2 = 70, i.e. exactly the official 70/70/138.
- **Injection protocol actually used by BOND (Sec. 3.2, App. A.1.3).** Structural: n non-overlapping groups of m nodes each, nodes made fully connected, then each edge dropped independently with probability p = 0.2 (a "camouflage" modification). Contextual: o nodes sampled without replacement; for each, q reference nodes are drawn from the remaining nodes and the node's attributes are replaced by those of the reference node at the largest Euclidean distance. BOND sets q = m and o = m x n, with m about twice the average degree and about 5% outliers. Table 6 for Cora as printed lists "n = 70, m = 10". Read literally that conflicts with "m x n structural outliers" (70 outliers would need n = 7 with m = 10). The printed row appears to hold the outlier count; this is our inference and should not be quoted as BOND's n.
- **Arithmetic cross-check (ours, not a source claim).** Edges grew from 10,556 (PyG Cora) to 11,060, i.e. +504 directed entries = 252 undirected = 0.8 x 315, where 315 = 7 cliques x C(10,2). That is consistent with 7 cliques of 10 nodes and p = 0.2.
- **This is not exactly Ding et al.'s protocol.** BOND modifies the widely used approach (edge dropping, disjoint reference set). If our report also injects anomalies itself, state m, n, k (candidates), p and the seed; do not describe the BOND file as "the DOMINANT injection".
- **Caveat.** Injected anomalies are synthetic and typed; detectors do much better on them than on organic anomalies (BOND Table 3 vs Table 4; Cora ROC-AUC mean: DOMINANT 82.7 +- 5.6, AnomalyDAE 83.4 +- 2.3). Cora here has had its class labels discarded for anomaly purposes.
- **Licence.** PyGOD data repo MIT (repository level). Licence of the underlying Cora data: not stated in any source opened.

## 5. Cora (Planetoid) provenance and our own injected variant

- **Statistics, three sources, three edge counts.** GCN paper Table 1 and GAT paper Sec. 3.1: Cora 2,708 nodes, **5,429** edges, 7 classes, 1,433 features, label rate 0.052 (GCN says it follows Yang et al. 2016). PyTorch Geometric's `Planetoid` doc: **10,556** edges (directed count). BOND/PyGOD inj_cora: 11,060 (after injection). The relation 10,556 = 2 x 5,278 versus 5,429 is not explained in any source opened (the 5,429 appears to count raw citation records before deduplication, but that is a guess; label UNVERIFIED). In the report, say which count you use and why.
- **Provenance.** Cora: citation network of machine-learning papers; nodes are papers, edges citations, features sparse bag-of-words, label one of seven classes (BOND A.1.1). Cited to Sen et al. (2008), "Collective Classification in Network Data", AI Magazine 29(3):93 (`sen2008collective`) by BOND, GCN and GAT. The original data descriptor McCallum et al. (2000), Information Retrieval 3(2):127-163, was NOT opened (UNVERIFIED in this folder). The Planetoid split/packaging is Yang, Cohen, Salakhutdinov, ICML 2016 (`yang2016planetoid`): 20 labelled nodes per class, 500 validation, 1,000 test (GCN Sec. 5.2).
- **Licence.** Not stated in any source opened (the LINQS page fetched had no dataset terms).
- **Ding et al. protocol parameters (secondary only).** The Ding et al. paper could not be opened. What was verified:
  - PyGOD's generator docs (cite Ding et al. 2019) describe it: structural = `m` nodes per clique, `n` cliques, so `m x n` structural outliers; contextual = `n` nodes chosen, for each sample `k` other nodes and copy attributes of the one with the largest Euclidean distance (`gen_contextual_outlier(data, n, k)`, `gen_structural_outlier(data, m, n, p=0)`).
  - ResGCN (Pei et al., arXiv) reports: clique size 15, clique counts 10, 15, 20 for BlogCatalog, Flickr, ACM, "the same as" Ding et al.; and as many attribute anomalies as structural ones.
  - CoLA (Liu et al., arXiv 2103.00113) reports clique size 15, counts 10, 15, 20, 5, 5, 20, 200 for BlogCatalog, Flickr, ACM, Cora, Citeseer, Pubmed, ogbn-arxiv; contextual candidate set k = 50 "to ensure the disturbance amplitude is large enough"; Cora total anomalies 150 (= 2 x 15 x 5).
  - CoLA attributes the contextual scheme to Song et al. (2007) (their ref. [64]) and structural to Ding et al.'s earlier WSDM 2019 paper (ref. [65]); ResGCN likewise credits Song et al. 2007 and Skillicorn 2007.
  - The official DOMINANT repositories do not ship an injection script (the PyTorch `utils.py` only loads `.mat` files with precomputed labels; datasets there are BlogCatalog, Flickr, ACM).
  - Safe wording for the report: "the injection scheme used in DOMINANT (Ding et al. 2019) and later work, with parameters m = ..., n = ..., k = ... chosen by us", and cite the secondary papers for typical values rather than claiming Ding et al. used a specific number.
